# Annotations live in a sidecar and are reified with human-wins precedence

Judgment-based features never land on components directly. `annotate_components.py --generate` writes LLM proposals to a sidecar of (component_id, feature, value, source) rows; `--import` converts Label Studio exports (human annotations and validity judgments on proposals) into sidecar rows; `--evaluate` reifies onto the components file under one universal rule: human annotations win where present (majority vote among multiple humans), otherwise the LLM proposal stands, with a printed count of features resting on unvalidated LLM judgment. Chosen so provenance (who said what) stays separate from consolidated truth, making re-generation and late-arriving human validation idempotent, without per-feature precedence configuration.
