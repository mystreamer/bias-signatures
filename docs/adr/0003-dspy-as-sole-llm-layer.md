# DSPy as the sole LLM layer

All LLM calls go through DSPy: signatures for structured calls (augmentation, annotation), and direct `dspy.LM.__call__` with a single bare user message for calls whose prompt must reach the model unadulterated — experiment runs of realised prompt templates and the stance classifier. This inlines the behaviour of the legacy `MinimalistAdapter(ChatAdapter)` (bare user message in, verbatim completion out) at the call layer instead of porting the class, which would have been dead code once raw calls stopped flowing through dspy.Predict. Rationale: one uniform provider/retry/config layer already proven in the legacy code, and prompt renderings stay consistent with the DSPy-rendered prompts documented in the thesis appendix. The plain-OpenAI-client alternative was rejected despite being lighter.
