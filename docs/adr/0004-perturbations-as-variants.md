# Perturbations are variants on base components, not new components

A perturbed or framed surface form (primed, grounded, abstracted, pro/con-framed) is stored in the `variants` map of its base component, not as an independent component row. This deviates from the formal model's literal π: C → C typing but preserves what the thesis actually relies on: partitions are σ-selections over the prompt template set, and `build_prompt_template_sets.py` stamps every emitted template row with explicit `perturbation` and `framing` columns. Chosen because it keeps one row per real-world topic, makes base↔variant lineage structural rather than bookkept via parent ids, and lets template sets be built declaratively ("base components, perturbed") — at the cost of components no longer being single-surface-form units.
